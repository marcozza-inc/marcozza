# Marcozza Inc. landing site

Static bilingual company site intended for `https://marcozza.com`. The French
page is the default at `/`, and the English page is available at `/en.html`.

## Preview

From this directory, run a local static file server and open the address it
prints. No build step or dependencies are required.

## Publishing

Publish these files from the public `marcozza-inc/marcozza` repository using
GitHub Pages. Configure `marcozza.com` as the custom domain only after the site
has been reviewed.

Do not copy private Agent Modeler documents, source code, credentials, customer
data, or unimplemented product/security claims into this public repository.
